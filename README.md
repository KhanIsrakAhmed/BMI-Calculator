# BMI Calculator

React BMI Calculator website with:

- BMI calculation
- BMI categorization
- Healthy weight range
- Approximate weight to lose/gain
- Light and dark mode
- Sun and moon theme switch icons
- Height input in centimeters or feet/inches
- Supports examples such as 5' 10"
- Responsive design

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000 in your browser.

## Build

```bash
npm run build
```
